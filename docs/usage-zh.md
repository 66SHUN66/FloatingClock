# 悬浮时钟 v1.2 · by SHUN

一个常驻桌面最上层的悬浮时钟 / 倒计时 / 秒表，专为 PPT、PDF 汇报、演讲、答辩场景设计。
双击 `悬浮时钟.exe` 即可运行，**不需要安装**（Windows 10/11 自带 .NET Framework 即可，无外部依赖）。

版本号与作者出现在三个地方：设置窗口的标题栏、设置页顶部（`悬浮时钟 · 1.2 · by SHUN`）、任务栏悬停提示。
设置面板可以**最小化**到任务栏（标题栏左侧那个「—」），随时点回来继续调。

---

## 1. 三个基础操作

| 想做的事 | 怎么做 |
| --- | --- |
| **放大 / 缩小窗口** | ① 鼠标滚轮在窗口上滚动（±8%/格）；② 拖**右下角**抓角自由拉伸；③ 设置里「窗口大小」滑块精确到 1%（40%–400%，保持当前长宽比）；④ 右键 → 还原窗口 400×160 |
| **换背景颜色** | 双击窗口（或右键 → 设置）打开设置面板，「背景与颜色」卡片点 7 个预设色块之一，或用取色器 / 手填色值改任意颜色 |
| **换数字字体** | 「数字字体」卡片点字体下拉框，列表里**每一行都用该字体本身渲染**并附 `12:34` 样例，选之前就能看到效果 |

> 数字默认「字号自动适配窗口」——窗口拉多大，数字就撑多大（约占窗口高度 52%），永远不会溢出。也可以关掉自动适配，用「字号大小」滑块手动定 16–260px。

---

## 2. 移动与位置

- **拖动**：在窗口任意非按钮区域按住左键拖动。靠近屏幕边缘 16px 会自动吸附。
- **锁定**：右键 → 锁定位置，或设置里打开「锁定位置和大小」，防止汇报时手滑挪动。
- 关闭后重新打开，**位置、尺寸、配色、字体全部记住**。

---

## 3. 三种模式

设置面板「显示模式」三选一，也可以用右键菜单切换。

- **时钟**：12/24 小时制、显示秒、显示日期星期（三档独立开关）。
- **倒计时**：底部有一条细进度条；最后阶段变红提醒；到点数字闪烁 + 可选响铃，并在 00:00 下方**持续显示「已超过 mm:ss」的加时读数**。
  - 「倒计时时长」滑块范围 15 秒 – 1 小时，**步进 1 秒**；滑块下方 `-1s` / `+1s` 按钮可以逐秒微调（滑块本身很难精确点中某一秒）。
  - 另有 1分 / 3分 / 5分 / 10分 / 15分 / 30分 / 45分 / 60分 八个一键预设。
  - 「最后 20% 变红」按总时长自适应（短计时不会一开始就全红）。
- **秒表**：`MM:SS.cc` 百分秒精度，适合排练单页讲解时长。

## 4. 快捷键

设置面板里，这张速查表就贴在「时钟 / 倒计时 / 秒表」切换器右边，开设置第一眼就能看到。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + Space` | 开始 / 暂停（全局生效，不用切窗口） |
| `Ctrl + Alt + R` | 重置当前计时 |
| `Ctrl + Alt + T` | 点击穿透开关（开启后鼠标点击直接落到 PPT 上，时钟完全不挡操作） |
| `空格` | 窗口获得焦点时开始 / 暂停 |
| `R` | 窗口获得焦点时重置 |
| `Esc` | 立刻隐藏顶部浮出的工具条 |

> **穿透模式怎么退出**：穿透开启后鼠标点不到时钟了，只能靠快捷键 —— 再按一次 `Ctrl + Alt + T`。

鼠标**悬停在窗口上**，顶部会浮出一排小按钮（开始/暂停、重置、设置、退出），2 秒无操作自动隐藏。
这排按钮的**尺寸跟随窗口缩放**：窗口缩到很小按钮不会小到点不中，放到 4 倍大按钮也会同步变大（限制在 0.8–2.2 倍之间）。万一还是嫌小，右键即可唤出完整菜单（模式切换、开始/暂停、重置、置顶、穿透、锁定、还原尺寸、设置、退出）。

## 5. 汇报专用

- **PPT / PDF 放映自动开始倒计时**：打开后每 0.6 秒检测前台窗口，识别到放映 / 全屏演示时自动开始（倒计时模式下还会自动切到倒计时并开跑），退出放映不影响计时。
  - PowerPoint / WPS 演示：窗口占屏宽 ≥90% 且类名是 `screenClass` / `PPTFrameClass` / `wppScreen` / `KWppScreen` / `KWppFrame`。
  - PDF 全屏演示：Acrobat、福昕（新版 `ApolloRuntimeContentWindow`）、WPS PDF、Edge / Chrome 浏览器放映，只要窗口标题带 `.pdf` **且宽、高都占屏 ≥90%** 就算开始演示 —— 所以用浏览器把 PDF 一键全屏翻页，也能自动起表。
- **底部文字可自定义**：见第 6 节，数字下面那行小字可以换成自己的文案（汇报人、单位、主题、页码都行）。
- **不抢 Alt-Tab**：时钟不出现在 Alt-Tab 列表里，任务栏有图标，不会污染窗口切换。
- **点击穿透**：汇报时开这个，时钟只是「贴」在屏幕上，翻页、批注、切窗口全都不受影响。
- **默认静音**：倒计时结束时不出声（演示现场突然"叮"一声很尴尬）；需要提醒时把「到时响铃」打开即可。

## 6. 底部文字（数字下面那行小字）

设置页「底部文字」卡片里填一段自己的文案，**默认是空的**（出厂就是空），此时数字下面显示自动文案：时钟显示日期星期、倒计时显示状态、超时显示加时读数。填了内容才会替换掉自动文案，清空立刻恢复。

文案里可以插入 5 个占位符，会实时替换成当前值：

| 占位符 | 替换成 |
| --- | --- |
| `{date}` | 今天日期，如 `2026-11-22` |
| `{time}` | 当前时间，如 `22:45:28` |
| `{mode}` | 当前模式：时钟 / 倒计时 / 秒表 |
| `{status}` | 当前状态，如 `倒计时进行中 · 空格暂停` |
| `{over}` | 加时读数，超时后才有值，如 `00:03` |

例：`第 3 页 · {status}` → 显示成「第 3 页 · 倒计时进行中 · 空格暂停」。
例：`{over} ｜ 第 3 页` → 超时后显示成「00:03 ｜ 第 3 页」。

> 即使自定义文案里没写 `{over}`，超时后程序也会自动在末尾补上「· 已超过 mm:ss」，加时读数不会被吞掉，并且整行按超时状态变红。

## 7. 配置文件

位置：`%APPDATA%\FloatingClock\config.ini`（纯文本 key=value，可直接编辑）

```ini
mode=clock          ; clock / countdown / stopwatch
x=.. y=.. w=.. h=..  ; 窗口位置与尺寸（逻辑像素）
bg=#101014           ; 背景色
fg=#ffffff           ; 文字色
alpha=0.95           ; 不透明度 0.35–1
font=Bahnschrift     ; 字体族名（系统中存在的任意字体）
bold=1 autofit=1 fontpx=100 spacing=2 shadow=1
showseconds=1 hour24=1 showdate=1
topmost=1 locked=0 clickthrough=0 pptauto=0
countdownsecs=300 beep=0 warnred=1 flashcolon=1
caption=            ; 底部文字，留空 = 自动文案，支持 {date} {time} {mode} {status} {over}
```

- **想恢复出厂设置**：直接删掉这个 `config.ini` 再启动。
- 程序崩溃会把异常写进同目录的 `error.log`。

## 8. 想改代码 / 重新编译

目录里同时提供了源码，改完双击 `构建.bat` 即可重新生成 `悬浮时钟.exe`：

| 文件 | 内容 |
| --- | --- |
| `悬浮时钟.cs` | 主窗口、绘制、计时逻辑、Win32 调用 |
| `Settings.cs` | 设置面板与全部自绘控件（卡片、开关、滑块、色板） |
| `FontPicker.cs` | 字体下拉框 + 弹出列表 |
| `悬浮时钟.ico` | 图标（16–256 多尺寸） |
| `构建.bat` | 一键编译（调用系统自带 csc.exe，无需 Visual Studio） |

编译用 Windows 自带的 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，产物是单文件原生 WinForms 程序，拷给任何 Win10/11 机器都能直接双击运行。

## 9. 常见问题

**Q：数字太大 / 太小，拉窗口没用？**
关掉「字号自动适配窗口」，用「字号大小」滑块手动指定。

**Q：想要一个精确的窗口尺寸？**
用「窗口大小」滑块，读数就是相对默认 400×160 的百分比：150% 就是 600×240（长宽比跟着你当前拖出来的形状走）。

**Q：字体列表里找不到我想要的字体？**
装好字体后重开设置面板即可 —— 列表读的是系统已安装的全部字体，推荐字体（Bahnschrift / DS-Digital / Impact / Consolas / 微软雅黑等）置顶。

**Q：调了透明度以后文字看不清？**
背景不透明度和文字色是分开的，把「文字颜色」设成纯白或纯黑，并适当降低背景不透明度会更好读。

**Q：窗口跑到屏幕外找不到了？**
任务栏点图标，或命令行 `悬浮时钟.exe --settings` 直接弹出设置面板，用「居中显示」拉回来。

**Q：设置页挡住 PPT 了，能收起来吗？**
能。设置页标题栏左侧有最小化按钮，点「—」就收到任务栏，时钟本体照常显示、照常计时。

**Q：我是用 PDF 讲课的，能像 PPT 那样自动起表吗？**
可以。把「PPT / PDF 放映自动开始倒计时」打开，然后用 Acrobat / 福昕 / WPS 打开 PDF 进全屏，或者直接用 Edge 打开 PDF 按 F11 全屏翻页，检测到「标题含 .pdf 且铺满整屏」就会自动开始倒计时。

**Q：底部那行字能换成我自己的话吗？**
能，设置页「底部文字」卡片里随便填，支持 `{date} {time} {mode} {status} {over}` 五个占位符；清空就恢复自动文案。
