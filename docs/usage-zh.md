# 悬浮时钟 v1.3.3 · by SHUN

一个常驻桌面最上层的悬浮时钟 / 倒计时 / 秒表，专为 PPT、PDF 汇报、演讲、答辩场景设计。
双击 `悬浮时钟.exe` 即可运行，**不需要安装**（Windows 10/11 自带 .NET Framework 即可，无外部依赖）。

版本号与作者出现在三个地方：设置窗口的标题栏、设置页顶部（`悬浮时钟 · 1.3.3 · by SHUN`）、任务栏悬停提示。
设置面板可以**最小化**到任务栏（标题栏左侧那个「—」），随时点回来继续调。

---

## 1. 三个基础操作

| 想做的事 | 怎么做 |
| --- | --- |
| **放大 / 缩小窗口** | ① 鼠标滚轮在窗口上滚动（±8%/格）；② 拖**右下角**抓角自由拉伸；③ 设置里「窗口大小」滑块精确到 1%（40%–400%，保持当前长宽比）；④ 右键 → 还原窗口 400×160 |
| **换背景颜色** | 双击窗口（或右键 → 设置）打开设置面板，「背景与颜色」卡片点 7 个预设色块之一，或用取色器 / 手填色值改任意颜色 |
| **换数字字体** | 「数字字体」卡片点字体下拉框，列表里**每一行都用该字体本身渲染**并附 `12:34` 样例，选之前就能看到效果 |

> 数字默认「字号自动适配窗口」——窗口拉多大，数字就撑多大（约占窗口高度 52%），永远不会溢出。也可以关掉自动适配，用「字号大小」滑块手动定 16–260px。

## 2. 移动与位置

- **拖动**：在窗口任意非按钮区域按住左键拖动。靠近屏幕边缘 16px 会自动吸附。
- **锁定**：右键 → 锁定位置，或设置里打开「锁定位置和大小」，防止汇报时手滑挪动。
- 关闭后重新打开，**位置、尺寸、配色、字体全部记住**。

## 3. 三种模式

设置面板「显示模式」三选一，也可以用右键菜单切换。

- **时钟**：12/24 小时制、显示秒、显示日期星期（三档独立开关）。
- **倒计时**：底部有一条细进度条；最后阶段变红提醒；到点数字闪烁 + 可选响铃，并在 00:00 下方**持续显示「已超过 mm:ss」的加时读数**。
  - 「倒计时时长」滑块范围 15 秒 – 1 小时，**步进 1 秒**；滑块下方 `-1s` / `+1s` 按钮可以逐秒微调（滑块本身很难精确点中某一秒）。
  - 另有 1分 / 3分 / 5分 / 10分 / 15分 / 30分 / 45分 / 60分 八个一键预设。
  - 「最后 20% 变红」按总时长自适应（短计时不会一开始就全红）。
  - **开始前预备（v1.3 新增）**：「预备秒数」滑块 0–10 秒，默认 3 秒。自动起表时先倒数 3-2-1（大字只显示一个数字，底下一行「准备开始 · 空格取消」，进度条同步走完），倒数结束才进入正式倒计时 —— 正好留出从讲台旁边走上台、点到第一页的时间。填 0 就关掉，回到「一开始就计时」的老行为。
    按 `空格` 可以中途取消预备、退回就绪状态。
- **秒表**：`MM:SS.cc` 百分秒精度，适合排练单页讲解时长。

## 4. 快捷键

设置面板里，这张速查表就贴在「时钟 / 倒计时 / 秒表」切换器右边，开设置第一眼就能看到。

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + Alt + Space` | 开始 / 暂停（全局生效，不用切窗口） |
| `Ctrl + Alt + R` | 重置当前计时 |
| `Ctrl + Alt + T` | 点击穿透开关（开启后鼠标点击直接落到 PPT 上，时钟完全不挡操作） |
| `空格` | 窗口获得焦点时开始 / 暂停 |
| `R` | 窗口获得焦点时重置 |
| `Esc` | 立刻隐藏顶部浮出的工具条 |

> **穿透模式怎么退出（v1.3 改进）**：穿透开启后，窗口右侧会固定显示两个小圆圈 —— 上面是「设置」，下面是「关闭」，**它们不会被穿透**，随时能点。其余位置依然把鼠标交给下面的 PPT。
> 也可以再按一次 `Ctrl + Alt + T` 关掉穿透。两个圈只在穿透状态出现，圆的大小随窗口缩放（16–30 逻辑像素之间自适应）。

鼠标**悬停在窗口上**，顶部会浮出一排小按钮（开始/暂停、重置、设置、退出），2 秒无操作自动隐藏。
这排按钮的**尺寸跟随窗口缩放**：窗口缩到很小按钮不会小到点不中，放到 4 倍大按钮也会同步变大（限制在 0.8–2.2 倍之间）。万一还是嫌小，右键即可唤出完整菜单（模式切换、开始/暂停、重置、置顶、穿透、锁定、还原尺寸、设置、退出）。

## 5. 汇报专用

- **PPT / PDF 放映自动开始倒计时**：打开后每 0.6 秒检测前台窗口，**只有真的开始放映、并且稳定保持 1.2 秒以上才起表**（v1.3 起严格判定，最大化窗口、编辑态全屏都不再误触发）。
  - PowerPoint：窗口类名必须是放映窗口的 `screenClass`，且窗口矩形**铺满整块屏幕（含任务栏区域，≥97%）**。
  - WPS 演示：新版 WPS 的放映窗口是 Qt 窗口（类名 `Qt5QWindowIcon`，和编辑器无关），所以改按「进程是 `wpp.exe` + 无边框 + 铺满整屏 ≥97%」判定；编辑器最大化时类是 `PP12FrameClass`、高度只到工作区，不会起表（v1.3.1 修）。
  - PDF 全屏演示：Acrobat、福昕（新版 `ApolloRuntimeContentWindow`）、WPS PDF、Edge / Chrome 浏览器放映 —— 要同时满足 ① 标题带 `.pdf`，② 无标题栏（真全屏），③ 铺满整屏（≥97%）。所以「把 PDF 拖成大窗口」「Acrobat 最大化」都不会起表，**F11 / 全屏阅读 / 点开始放映之后才起表**。
  - **任意窗口全屏（v1.3.2 提供，默认关）**：打开这个开关后，不管是什么软件，只要前台窗口无标题栏且铺满整屏（含任务栏，≥97%）、稳定 1.2 秒，就当作「开讲了」自动起表；桌面、任务栏、任务视图/Alt-Tab 这类系统窗口被排除。因为它对全屏视频同样生效，v1.3.3 起改成默认关闭，需要时到设置页「窗口行为」卡片里自己勾上。
  - 起表后先走「开始前预备」的 3-2-1，再进入正式倒计时（见第 3 节）；退出放映不影响已经跑起来的计时。
- **底部文字可自定义**：见第 6 节，数字下面那行小字可以换成自己的文案（汇报人、单位、主题、页码都行）。
- **不抢 Alt-Tab**：时钟不出现在 Alt-Tab 列表里，任务栏有图标，不会污染窗口切换。
- **点击穿透**：汇报时开这个，时钟只是「贴」在屏幕上，翻页、批注、切窗口全都不受影响；右侧两个圆圈保持可点，随时能开设置或退出。
- **默认静音**：倒计时结束时不出声（演示现场突然"叮"一声很尴尬）；需要提醒时把「到时响铃」打开即可。

## 6. 底部文字（数字下面那行小字）

设置页「底部文字」卡片里填一段自己的文案，**默认是空的**（出厂就是空），此时数字下面显示自动文案：时钟显示日期星期、倒计时显示状态、超时显示加时读数。填了内容才会替换掉自动文案，清空立刻恢复。

文案里可以插入 5 个占位符，会实时替换成当前值：

| 占位符 | 替换成 |
| --- | --- |
| `{date}` | 今天日期，如 `2026-11-22` |
| `{time}` | 当前时间，如 `22:45:28` |
| `{mode}` | 当前模式：时钟 / 倒计时 / 秒表 |
| `{status}` | 当前状态，如 `倒计时进行中 · 空格暂停` |
| `{over}` | 加时读数，超时后才有值，如 `00:03` |

例：`第 3 页 · {status}` → 显示成「第 3 页 · 倒计时进行中 · 空格暂停」。
例：`{over} ｜ 第 3 页` → 超时后显示成「00:03 ｜ 第 3 页」。

> 即使自定义文案里没写 `{over}`，超时后程序也会自动在末尾补上「· 已超过 mm:ss」，加时读数不会被吞掉，并且整行按超时状态变红。

## 7. 配置文件

位置：`%APPDATA%\FloatingClock\config.ini`（纯文本 key=value，可直接编辑）

```ini
mode=clock          ; clock / countdown / stopwatch
x=.. y=.. w=.. h=..  ; 窗口位置与尺寸（逻辑像素）
bg=#101014           ; 背景色
fg=#ffffff           ; 文字色
alpha=0.95           ; 不透明度 0.35–1
font=Bahnschrift     ; 字体族名（系统中存在的任意字体）
bold=1 autofit=1 fontpx=100 spacing=2 shadow=1
showseconds=1 hour24=1 showdate=1
topmost=1 locked=0 clickthrough=0 pptauto=0 fullauto=0
countdownsecs=300 preroll=3 beep=0 warnred=1 flashcolon=1
caption=            ; 底部文字，留空 = 自动文案，支持 {date} {time} {mode} {status} {over}
```

- **想恢复出厂设置**：直接删掉这个 `config.ini` 再启动。
- 程序崩溃会把异常写进同目录的 `error.log`。

源码在 `源码\` 目录里（v1.3 按类拆成 7 个文件，放在 `源码\src\`）。改完直接双击：

- `源码\build\build.bat` → 两个一起编

| `ClockFormCore.cs` | 悬浮窗口（上）：字段、计时器、排版与数字绘制、穿透圆圈 |
| `ClockFormUi.cs` | 悬浮窗口（下）：悬浮工具条、右键菜单、模式切换、几何、放映检测 |

| `悬浮时钟.ico` / `源码\assets\app.ico` | 图标（16–256 多尺寸） |

编译用 Windows 自带的 `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`，产物是单文件原生 WinForms 程序，拷给任何 Win10/11 机器都能直接双击运行。
加上 `/define:EN` 就是英文版（只改默认语言）。

## 9. 常见问题

**Q：数字太大 / 太小，拉窗口没用？**
关掉「字号自动适配窗口」，用「字号大小」滑块手动指定。

**Q：想要一个精确的窗口尺寸？**
用「窗口大小」滑块，读数就是相对默认 400×160 的百分比：150% 就是 600×240（长宽比跟着你当前拖出来的形状走）。

**Q：字体列表里找不到我想要的字体？**
装好字体后重开设置面板即可 —— 列表读的是系统已安装的全部字体，推荐字体（Bahnschrift / DS-Digital / Impact / Consolas / 微软雅黑等）置顶。

**Q：调了透明度以后文字看不清？**
背景不透明度和文字色是分开的，把「文字颜色」设成纯白或纯黑，并适当降低背景不透明度会更好读。

**Q：窗口跑到屏幕外找不到了？**
任务栏点图标，或命令行 `悬浮时钟.exe --settings` 直接弹出设置面板，用「居中显示」拉回来。

**Q：设置页挡住 PPT 了，能收起来吗？**
能。设置页标题栏左侧有最小化按钮，点「—」就收到任务栏，时钟本体照常显示、照常计时。

**Q：我是用 PDF 讲课的，能像 PPT 那样自动起表吗？**
可以。把「PPT / PDF 放映自动开始倒计时」打开，然后用 Acrobat / 福昕 / WPS 打开 PDF 进全屏（Ctrl+L 全屏阅读），或者直接用 Edge 打开 PDF 按 F11 全屏翻页。v1.3 的判定是「标题含 .pdf + 无标题栏 + 铺满整屏 ≥97% + 稳定 1.2 秒」——真的进入放映态之后才起表，先走一遍 3-2-1 预备再正式计时。

**Q：为什么 v1.2 里「一打开 PPT 就开始倒计时」，v1.3 不会了？**
因为 v1.3 收紧了判定：只认真正的放映窗口，并且必须铺满整块屏幕；把 PPT 最大化只是编辑窗口，不再触发。这样你打开 PPT 改稿、或者文件刚打开还没点「放映」，计时都不会自己跑起来。

**Q：我用的是 WPS 演示，v1.3 里按 F5 放映也不起表，v1.3.1 好了吗？**
好了。症结是 WPS 新版放映窗口属于 Qt 窗口（类名 `Qt5QWindowIcon`），老版本只认 PowerPoint 的 `screenClass` 系列，所以整个放映态都没被识别。v1.3.1 增加了「进程名 `wpp.exe` + 无边框 + 铺满整屏」这条判定，实机对照验证过：WPS 编辑器前台放 3 秒不起表，按 F5 出来才走 3-2-1。

**Q：我在全屏看视频 / 全屏打开别的软件，会误起表吗？**
默认不会。v1.3.2 加的「任意窗口全屏时自动开始倒计时」这条判据在 v1.3.3 里改成**默认关闭**，出厂只走 PPT / PDF 那条严格判据；想让它对你所有全屏软件都生效，就到设置页「窗口行为」卡片里把开关打开。

**Q：放映窗口为什么慢半拍才起表？**
检测每 0.6 秒一轮，还要求放映态稳定保持 1.2 秒（防止 Alt-Tab 闪烁误触），所以点下「放映」到看到 3-2-1 之间大约有 1~2 秒延迟，属于正常。

**Q：预备 3-2-1 太长 / 想关掉？**
设置页「倒计时」卡片里「开始前预备」滑块拉到 0 就是关闭，拉到 5 就是 5 秒。手动按空格开始时不走预备，直接计时（保证手动起表还是精确的）。

**Q：底部那行字能换成我自己的话吗？**
能，设置页「底部文字」卡片里随便填，支持 `{date} {time} {mode} {status} {over}` 五个占位符；清空就恢复自动文案。

## 10. 英文版与 GitHub

同一份源码编译出两个语言版本，文件名决定它是哪一个：

| 可执行文件 | 界面语言 | 配置文件（互不干扰） |
| --- | --- | --- |
| `悬浮时钟.exe`（仓库构建产物叫 `FloatingClock-ZH.exe`） | 中文 | `%APPDATA%\FloatingClock\config.ini` |
| `FloatingClock.exe` | English | `%APPDATA%\FloatingClock\config-en.ini` |

两个版本可以同时开着用：配置分开存，语言和窗口位置都不会互相踩。

也可以直接在界面里换：设置页最上方「语言 / Language」分段控件点一下，整个对话框立刻按新语言重建（中文版里切成 English、英文版里切回中文都行），选择写进配置文件，下次启动沿用。
英文版里快捷键表是 4 行版式（比中文多一行 `Ctrl+Alt+R: reset`），设置页顶部名称按语言自适应宽度，这些都已经按英文重新排过。

### v1.3 的实现要点（给看代码的人）

- **穿透圆圈**：不再给窗口加 `WS_EX_TRANSPARENT`（那会让整窗命中测试失效、所有子按钮都点不到），改在 `WndProc` 里处理 `WM_NCHITTEST`：命中两个圆圈矩形返回 `HTCLIENT`，其余位置返回 `HTTRANSPARENT`，鼠标照样落到下层 PPT —— 跨进程同样有效。圆圈位置在 `DrawPod()` 绘制时记进 `podSettings` / `podClose` 两个字段，`OnMouseDown` 里据此分发到设置 / 关闭。
- **预备倒计时**：`preRunning` / `preEnd` / `preTotal` 三个状态 + `Compose()` 里的独立分支；`OnTick()` 到点后把 `cdEnd = now + cdTotal` 交给正式倒计时，两段无缝衔接。
- **放映检测**：`OnWatchSlideshow()` 只认放映窗口类名，并用 `GetWindowLong(GWL_STYLE) & WS_CAPTION` 判断是否无标题栏；覆盖率按 `Screen.Bounds`（含任务栏）算到 97%，再用 `showSince` 要求状态持续 1.2 秒，避免 Alt-Tab 闪烁误触。
- **v1.3.2 的全屏兜底**：`OnWatchSlideshow()` 里多一条独立判据 `FullAuto`，与 PPT/PDF 规则并列；用 `IsShell(cls)` 排除 `Progman / WorkerW / Shell_TrayWnd / XamlExplorerHostIslandWindow / MultitaskingViewFrame / TaskSwitcherWnd`，仍沿用「无标题栏 + 覆盖 ≥97% + 稳定 1.2 秒」。起表判定改成 `(isShow||isPdf) ? (PptAuto||FullAuto) : FullAuto`，所以全屏开关是 PPT 开关的超集。
- **v1.3.1 的 WPS 修正**：加 `GetWindowThreadProcessId` + `ProcessName(h)`（`Process.GetProcessById(pid).ProcessName`），在 `OnWatchSlideshow()` 里补两条规则 —— 放映：`cls == "Qt5QWindowIcon" && proc == "wpp"`；PDF：`cls == "Qt5QWindowIcon" && proc ∈ {wpspdf, wps, wpp}` 且标题含 `.pdf`。铺满整屏与 1.2 秒稳定性作为兜底不变，所以 WPS 编辑器最大化（`PP12FrameClass`、高度只到工作区 95%）永远不会被误判。
